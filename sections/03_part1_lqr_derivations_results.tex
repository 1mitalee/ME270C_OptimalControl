\subsection{Fixed-Time LQR Problem}

The linear models derived in the previous subsections are written in deviation variables. For a nominal trajectory
\[
    x^\star(t), \qquad u^\star(t),
\]
we define
\[
    \delta x(t)=x(t)-x^\star(t),
    \qquad
    \delta u(t)=u(t)-u^\star(t).
\]
The corresponding linearized dynamics have the form
\[
    \delta \dot x(t)
    =
    A(t)\delta x(t)+B(t)\delta u(t).
\]
For the hover linearization, the frozen-mass approximation gives constant matrices \(A\) and \(B\), so the system is time-invariant. For the non-hover nominal trajectories, the matrices \(A(t)\) and \(B(t)\) vary along the trajectory, so the system is time-varying.

Since the linearized state and input are deviations from a nominal trajectory, we define the LQR cost function in the same deviation coordinates. Thus the finite-horizon quadratic regulation problem is
\[
    \min_{\delta u(\cdot)}
    J
    =
    \int_0^{t_f}
    \left(
        \delta x(t)^\top Q\delta x(t)
        +
        \delta u(t)^\top R\delta u(t)
    \right)dt
    +
    \delta x(t_f)^\top Q_f \delta x(t_f),
\]
subject to
\[
    \delta \dot x(t)
    =
    A(t)\delta x(t)+B(t)\delta u(t),
    \qquad
    \delta x(0)=x_0-x^\star(0).
\]
Here \(Q\succeq 0\), \(Q_f\succeq 0\), and \(R\succ 0\). The matrix \(Q\) penalizes deviation of the state from the nominal trajectory, \(R\) penalizes deviation of the input from the nominal input, and \(Q_f\) penalizes terminal deviation. This convention is important: for example, in the hover case the physical thrust is recovered as
\[
    T(t)=T^\star+\delta T(t),
\]
so the control cost penalizes the thrust correction \(\delta T\), not the full thrust magnitude \(T\).



\subsection{PMP and Riccati Derivation}

For the time-varying linearized system, define the Hamiltonian
\[
    H(\delta x,\delta u,\lambda,t)
    =
    \delta x^\top Q\delta x
    +
    \delta u^\top R\delta u
    +
    \lambda^\top\left(A(t)\delta x+B(t)\delta u\right),
\]
where \(\lambda(t)\) is the costate. Pontryagin's Maximum Principle gives
\[
    \delta \dot x
    =
    \frac{\partial H}{\partial \lambda}
    =
    A(t)\delta x+B(t)\delta u,
\]
\[
    \dot\lambda
    =
    -\frac{\partial H}{\partial (\delta x)}
    =
    -2Q\delta x-A(t)^\top\lambda,
\]
and the stationarity condition
\[
    0
    =
    \frac{\partial H}{\partial (\delta u)}
    =
    2R\delta u+B(t)^\top\lambda.
\]
Therefore, the unconstrained optimal deviation input is
\[
    \delta u^*(t)
    =
    -\frac{1}{2}R^{-1}B(t)^\top\lambda(t).
\]
The terminal cost gives the transversality condition
\[
    \lambda(t_f)
    =
    2Q_f\delta x(t_f).
\]

The LQR structure is obtained by using the quadratic value-function ansatz
\[
    V(t,\delta x)=\delta x^\top P(t)\delta x.
\]
Then
\[
    \lambda(t)
    =
    \frac{\partial V}{\partial(\delta x)}
    =
    2P(t)\delta x(t).
\]
Substituting this expression into the stationarity condition gives the optimal feedback law
\[
    \delta u^*(t)
    =
    -R^{-1}B(t)^\top P(t)\delta x(t).
\]
Thus the feedback gain is
\[
    K(t)=R^{-1}B(t)^\top P(t),
\]
and the closed-loop linearized dynamics are
\[
    \delta \dot x(t)
    =
    \left(A(t)-B(t)K(t)\right)\delta x(t).
\]

The Riccati differential equation is
\[
    -\dot P(t)
    =
    A(t)^\top P(t)+P(t)A(t)
    -P(t)B(t)R^{-1}B(t)^\top P(t)
    +Q,
\]
with terminal condition
\[
    P(t_f)=Q_f.
\]
For the frozen-mass hover linearization, \(A(t)=A\) and \(B(t)=B\), so the Riccati equation reduces to the standard finite-horizon LTI Riccati equation
\[
    -\dot P(t)
    =
    A^\top P(t)+P(t)A
    -P(t)BR^{-1}B^\top P(t)
    +Q,
    \qquad
    P(t_f)=Q_f.
\]
For the non-hover nominal trajectories, the same Riccati equation is solved with the time-varying matrices \(A(t)\) and \(B(t)\) obtained from trajectory linearization.

The resulting optimal physical control is recovered from the nominal input by
\[
    u^*(t)
    =
    u^\star(t)+\delta u^*(t).
\]
In particular, for the hover case,
\[
    T^*(t)=T^\star+\delta T^*(t),
    \qquad
    \tau^*(t)=\tau^\star+\delta\tau^*(t).
\]
For hover, \(T^\star=m_hg\) and \(\tau^\star=0\). For a general nominal trajectory, \(T^\star(t)\) and \(\tau^\star(t)\) are the nominal thrust and torque used to generate the reference trajectory.

\subsection{Numerical Results and Interpretation}

We next compare the hover LQR solution under several choices of the weighting matrices \(Q\), \(R\), and \(Q_f\). The purpose of this experiment is not only to solve one LQR instance, but also to understand how the relative weights on state deviation, terminal error, and control effort affect the resulting closed-loop behavior.

All simulations are performed over the fixed time interval
\[
    t\in[0,5],
\]
using \(501\) uniformly spaced time points. The hover trim state used for this experiment is
\[
    x^\star
    =
    \begin{bmatrix}
        0 & 200 & 0 & 0 & 0 & 0 & 20
    \end{bmatrix}^{\top}.
\]
The initial perturbation from hover is
\[
    \delta x(0)
    =
    \begin{bmatrix}
        10 &
        20 &
        -5 &
        5 &
        5^\circ &
        2.5^\circ &
        0.5
    \end{bmatrix}^{\top},
\]
where angular quantities are converted to radians in the numerical implementation. The physical initial state is therefore \(x(0)=x^\star+\delta x(0)\), so the reconstructed position starts from \((p_x(0),p_z(0))=(10,220)\).

For comparison with the non-hover linearizations considered in Section~1.2, the same configuration file also defines the nominal descent initial condition
\[
    x_{\mathrm{nom}}(0)
    =
    \begin{bmatrix}
        0 & 200 & 100 & -20 & 0 & 0 & 20
    \end{bmatrix}^{\top}.
\]
The nominal thrust is chosen as
\[
    T_{\mathrm{nom}} = mg(1+\beta),
    \qquad
    \beta=0.05.
\]
For the attitude-coupled nominal trajectory, the prescribed attitude is
\[
    \theta^\star(t)=a\sin(bt),
    \qquad
    a=5^\circ,
    \qquad
    b=1.
\]
The present subsection focuses on the hover LQR case; the non-hover trajectories are used later for the controllability comparison.

\subsubsection{Weighting matrices}

The baseline weighting matrices are chosen using inverse-square normalization. If \(s_i\) denotes the reference scale for the \(i\)-th state component and \(r_j\) denotes the reference scale for the \(j\)-th input component, then
\[
    Q_{\mathrm{base}}
    =
    \operatorname{diag}\left(\frac{1}{s_1^2},\ldots,\frac{1}{s_7^2}\right),
    \qquad
    R_{\mathrm{base}}
    =
    \operatorname{diag}\left(\frac{1}{r_1^2},\frac{1}{r_2^2}\right).
\]
The baseline terminal cost is
\[
    Q_{f,\mathrm{base}} = 10Q_{\mathrm{base}}.
\]
We compare five choices:
\[
\begin{array}{c|c|c|c}
\text{Case} & Q & R & Q_f \\
\hline
\texttt{baseline\_normalized}
&
Q_{\mathrm{base}}
&
R_{\mathrm{base}}
&
10Q_{\mathrm{base}}
\\
\texttt{high\_terminal\_penalty}
&
Q_{\mathrm{base}}
&
R_{\mathrm{base}}
&
50Q_{\mathrm{base}}
\\
\texttt{high\_position\_attitude\_penalty}
&
Q_{\mathrm{pa}}
&
R_{\mathrm{base}}
&
10Q_{\mathrm{base}}
\\
\texttt{high\_control\_penalty}
&
Q_{\mathrm{base}}
&
10R_{\mathrm{base}}
&
10Q_{\mathrm{base}}
\\
\texttt{low\_control\_penalty}
&
Q_{\mathrm{base}}
&
0.1R_{\mathrm{base}}
&
10Q_{\mathrm{base}}
\end{array}
\]
where \(Q_{\mathrm{pa}}\) is obtained from \(Q_{\mathrm{base}}\) by multiplying the running penalties on \(p_x\), \(p_z\), and \(\theta\) by a factor of \(10\).

\subsubsection{Trajectory comparison}

Figure~\ref{fig:hover-physical-trajectory} shows the reconstructed physical trajectories in the \((p_x,p_z)\)-plane. All trajectories start from the same perturbed physical initial state, so the differences are due only to the choices of \(Q\), \(R\), and \(Q_f\).

\begin{figure}[htbp]
    \centering
    \includegraphics[width=0.90\columnwidth]{figures/hover_physical_position_trajectory.png}
    \caption{Reconstructed physical trajectories for the hover LQR experiment under different weighting matrices.}
    \label{fig:hover-physical-trajectory}
\end{figure}

The baseline normalized controller gives a moderate response. The high-control-penalty case is the most conservative: since control effort is expensive, both \(\delta T\) and \(\delta\tau\) remain relatively small, and the state deviations are corrected slowly. In contrast, the low-control-penalty case uses larger thrust and torque corrections and produces a more aggressive response. The high-terminal-penalty case also produces aggressive transient behavior because it places more emphasis on reducing the final deviation at \(t_f\).

\subsubsection{State deviation histories}

Figures~\ref{fig:hover-delta-px}--\ref{fig:hover-delta-m} show the time histories of the state deviations. The horizontal position deviation \(\delta p_x\) increases for all cases because the initial horizontal velocity deviation is significant. However, the high-terminal-penalty controller reduces \(\delta v_x\) most aggressively and therefore produces the smallest terminal horizontal-position deviation among the tested cases. The high-control-penalty case keeps the control effort small, so the horizontal velocity remains comparatively large and the horizontal position continues to drift.

The attitude and angular velocity histories show the mechanism by which horizontal corrections are generated near hover. Since horizontal acceleration is produced primarily by tilting the thrust vector, the LQR controller uses torque to shape \(\delta\theta\) and \(\delta\omega\). Penalizing attitude more heavily keeps \(\delta\theta\) closer to zero, but this can also reduce the controller's ability to generate horizontal acceleration over a short horizon.

\subsubsection{Control histories}

Figures~\ref{fig:hover-delta-T} and~\ref{fig:hover-delta-tau} show the thrust and torque deviations. These plots make the tradeoff between performance and control effort explicit. The high-control-penalty case has the smallest control magnitudes and the slowest state correction. The low-control-penalty case uses the largest initial control magnitudes, especially in torque, and produces a more aggressive state response. The baseline and high-position-attitude-penalty cases lie between these two extremes.

\begin{figure}[htbp]

Overall, these simulations show the expected LQR tradeoff. Increasing the terminal penalty encourages stronger correction near the end of the horizon. Increasing the control penalty produces smoother but less corrective behavior. Decreasing the control penalty allows aggressive inputs and faster state response, but at the cost of larger thrust and torque deviations. The normalized baseline provides a balanced reference configuration for subsequent comparisons.
